# Nexus IA — Seu Funcionário Virtual de Vendas com IA

Welcome to the **Nexus IA** repository! This is a modern React application built to provide a virtual AI sales assistant that prospects, qualifies leads, and conducts sales on WhatsApp 24/7.

## 🚀 Features
- **AI Sales Assistant:** Automates WhatsApp interactions to qualify leads.
- **Modern UI/UX:** Built with React, Tailwind CSS, and Shadcn UI.
- **Responsive Design:** Works seamlessly on desktop and mobile devices.
- **Supabase Integration:** Connects to Supabase for secure backend functions.

## 🛠️ Tech Stack
- **Frontend Framework:** React 18 with Vite
- **Styling:** Tailwind CSS & Shadcn UI
- **Routing:** React Router
- **Data Fetching:** React Query
- **Backend/Functions:** Supabase

## 📦 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
```sh
git clone https://github.com/Elierickc/prompt-powered-ventures.git
cd prompt-powered-ventures
```

2. Install dependencies:
```sh
npm install
```

3. Start the development server:
```sh
npm run dev
```
